Licences of the ESP-Mosaico demo firmware in this directory
===========================================================

Files: s31-mosaico-demo-bootloader.bin, s31-mosaico-demo-ptable.bin, s31-mosaico-demo.bin

The page demo s31-mosaico (web/wasm/fw/s31-mosaico.json) for Espressif's ESP-Mosaico
(ESP32-S31). Built with ESP-IDF v6.1 (commit fff9895c82d744c7237be8847347bdd1b07c6643) by
tools/fetch-s31-firmware.sh in this repository, which pins all three files by SHA-256: the source
is examples/mosaico-demo (its sdkconfig.defaults and dependencies.lock), with the components
esp-mosaico-bsp, espressif__spi_nand_flash and espressif__dhara of
https://github.com/esp-mosaico/esp-mosaico-bsp at commit 841f6245850e84ec210ec1818db148e9c3172e4e
copied into its components/ directory, and the BSP's idf_component.yml changed by
tools/s31-mosaico-demo/esp-mosaico-bsp-idf-6.1.patch (its ESP-IDF requirement, ">=6.2", becomes
">=6.1"; no source file is changed). The source of everything below is at those revisions and in
the components dependencies.lock pins.

The application (examples/mosaico-demo/main) is from this repository, MIT (the repository's
LICENSE).

Linked components (dependencies.lock): lvgl/lvgl 9.5.0 (MIT); esp-mosaico-bsp 0.2.0 at the commit
above, espressif/esp_lvgl_adapter 0.6.2, espressif/esp_lcd_co5300 2.2.0, espressif/esp_lcd_touch
1.2.1, espressif/esp_lcd_touch_cst9220 0.1.2, espressif/button 4.2.3 and espressif/i2c_bus 1.5.2
(Apache-2.0); espressif/bmi270_sensor 0.4.1 (Apache-2.0; its prebuilt library contains Bosch
Sensortec's BMI270 SensorAPI and configuration image, BSD-3-Clause); espressif/bmm150 1.1.0
(BSD-3-Clause, Bosch Sensortec and Espressif); espressif/libpng 1.6.59~1 (libpng) and
espressif/zlib 1.4.0 (zlib), of which a few hundred bytes are linked. The other components in the
lock file (bq27220, esp_codec_dev, spi_nand_flash, dhara, esp_lv_decoder, esp_lv_fs,
esp_mmap_assets, esp_new_jpeg, freetype, qoi, knob, cmake_utilities) are not linked: the image's
map file shows no code or data from them.
