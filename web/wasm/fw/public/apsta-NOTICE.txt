ESP32, ESP32-S3, ESP32-C3 and ESP32-C6 Wi-Fi AP+STA firmware
============================================================

Files: classic-wifi_apsta.bin, s3-wifi_apsta.bin, c3-wifi_apsta.bin, c6-wifi_apsta.bin. They
run with the softap bootloaders and partition tables (classic-softap-*.bin, {s3,c3,c6}-softap-*.bin),
which examples/wifi-apsta builds byte for byte; those files' notices are
classic-softap-NOTICE.txt and softap-NOTICE.txt.

They are examples/wifi-apsta (this repository, MIT) built with ESP-IDF v5.5.4 for each chip, as
described in that example's README: Xtensa GCC esp-14.2.0_20260121 for the classic ESP32 and the
S3, RISC-V GCC esp-14.2.0_20260121 for the C3 and C6. ESP-IDF sources and pinned submodules:
https://github.com/espressif/esp-idf/tree/v5.5.4

Linked components and licences
------------------------------
The application link maps were inspected for archives with retained, nonzero sections. This
list describes the linked subset, not every library available in ESP-IDF.

* ESP-IDF (system, drivers, NVS, netif, event loop, Wi-Fi driver) and Espressif's binary
  Wi-Fi/PHY libraries (libnet80211, libpp, libphy, libcore, libespnow; librtc on the classic
  ESP32; libmesh on the C3 and C6; libcoexist on the C6): Espressif Systems, Apache-2.0.
* wpa_supplicant (ESP-IDF's port: the access point's authenticator and the station's
  supplicant): Jouni Malinen and contributors, BSD.
* Mbed TLS (its crypto library, used by wpa_supplicant): ARM Limited and contributors,
  Apache-2.0.
* FreeRTOS: Amazon.com and contributors, MIT.
* lwIP: Swedish Institute of Computer Science and contributors, BSD-3-Clause.
* TLSF allocator: Matthew Conte, BSD-3-Clause.
* newlib C runtime: its per-file copyright holders and licences.
* GCC runtime (libgcc, libstdc++): Free Software Foundation and contributors, GPL-3.0 with GCC
  Runtime Library Exception 3.1. Both texts are included in crypto-tls-runtime-licenses.txt.

The FreeRTOS, lwIP, wpa_supplicant, TLSF, newlib and Apache-2.0 licence texts and copyright
notices are already distributed in wifi-station-NOTICE.txt, starting at its individually
labelled licence sections. That file's general ESP-IDF inventory is not the linked-component
list for this firmware.

The SSIDs and passphrases in the images (esp32sim-ap / esp32sim-pass for the access point,
esp32sim / esp32sim-pass for the station) are public test inputs, never production credentials.
