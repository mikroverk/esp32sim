# Browser regions and PIE results — 2026-09-06

The TinyDraw gate-1 workload on the Waveshare AMOLED 1.8 V2 model took **21.7% less wall time** with the browser engine changes in [PR #63](https://github.com/mikroverk/esp32sim/pull/63). Three alternating pairs gave medians of 115.55 seconds on `ea1de070` and 90.42 seconds on `ddaac9af`. All six runs passed all 36 firmware checks, completed exactly 9,819,885,134 instructions, produced identical console output, and reported zero JIT compilation failures.

The [compact receipt](2026-09-06-regions-pie.json) contains individual timings, execution order, build and input hashes, browser/toolchain versions, verdicts, generated-code statistics, and the page-test summary. The runs used Chrome 152.0.7977.77 / V8 15.2.124.19 and Rust 1.98.0, with ordinary release WASM builds and profiling disabled.

The workload advances 47.75 modeled guest seconds: the candidate reaches 0.53× modeled realtime. This is one firmware workload and three pairs, not a hardware clock validation or a statistical confidence guarantee. Peak live generated bytes increased from 32,671,121 to 51,146,202. Separate production-page mouse tests rendered three complete strokes during contact and delivered every sampled input to the worker and a subsequent emulator run; those timestamps do not measure optical presentation.

## Reproduce

From a checkout containing PR #62, create the two engine checkouts and use the asset-map format in the [benchmark instructions](../README.md). To reproduce this workload, provide local assets matching the receipt's hashes; a different firmware requires its own justified instruction-count baseline.

```sh
git fetch https://github.com/aliceisjustplaying/esp32sim.git perf/browser-regions-pie
git worktree add --detach target/regions-baseline ea1de070
git worktree add --detach target/regions-candidate ddaac9af
python3 tools/browser-benchmark/run-pairs.py target/regions-recheck \
  --baseline-tree target/regions-baseline \
  --candidate-tree target/regions-candidate \
  --assets /absolute/path/assets.json --pairs 3
```

Keep other builds and simulator runs stopped during timing. The output directory must be new. Battery timings exclude canvas rendering; assess drawing separately using the page tests.
